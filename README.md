# Peer review

Work through peer review from both sides: plan a revision, answer reviewers, mark the changes, write the cover letter or a conference rebuttal, review your own draft, and draft a referee report.

A JointTex skill set. Publish this repository from the JointTex plugin marketplace (Plugins, Publish skills) with the values below; each skill is `skills/<name>/SKILL.md`.

- Name: Peer review (zh: 同行评审)
- Summary: Plan a revision, answer reviewers point by point, mark the changes, and write the cover letter, a conference rebuttal or a referee report.
- Summary (zh): 规划返修、逐条回复审稿意见、标注修改，并起草 cover letter、会议 rebuttal 或审稿报告。
- Fields: general, writing

## Skills

As an author, after a decision:

- `revision-plan`: Sort reviewer and editor comments into a revision plan, with an action, an owner and a status for each point, before any reply is written.
- `response-to-reviewers`: Draft a point-by-point response to reviewer comments, tied to the changes made in the manuscript.
- `mark-changes`: Mark the revised passages in a LaTeX manuscript for a resubmission, and produce the list of changes with their locations.
- `conference-rebuttal`: Write a conference rebuttal or author response within the venue length limit, answering the concerns the decision turns on first.
- `cover-letter`: Write a submission or resubmission cover letter from the manuscript and the target journal.

Before submission:

- `self-review`: Review your own manuscript the way a critical referee would before submission, and list the objections worth fixing first.

As a reviewer:

- `referee-report`: Help write a referee report on a manuscript under review, with a summary, major and minor concerns tied to locations, and a recommendation.

## How they fit together

A journal revision usually runs `revision-plan`, then the manuscript edits, then `response-to-reviewers`, `mark-changes` and `cover-letter`. A conference with a short author response uses `conference-rebuttal` in place of the first three.

## What the skills will not do

They do not invent reviewer comments, results, references or author statements. Anything the project or the collaborator did not supply is left as a marked placeholder and listed at the end. Scientific concessions, the recommendation in a referee report, and whether a journal permits an AI assistant during review are the collaborator's decisions; `referee-report` asks about the last one before reading the manuscript.
